ВСЕ СЕРВЕРЫ

Настройки игрового сервера

Для регистрации сервера достаточно войти в свой аккаунт Company 2010.

Сервер должен быть запущен отдельно. Сайт только публикует адрес и проверяет регулярные отчёты запущенного сервера.

Плагины в сервере версии 1.3 пока не исполняются: это сетевой TCP-relay для двух игроков.

Сервер зарегистрирован — сохраните настройки!

Создайте файл server_config.json рядом с vvb_dedicated_server.py и вставьте в него этот текст. Токен будет показан только один раз.


        
        
        
        
На компьютере владельца запустите start_server.bat. Откройте TCP-порт на роутере и в брандмауэре. Сайт не запускает игру сам.

ТОКЕН И КОНФИГУРАЦИЯ

        
Если забыли heartbeat-токен, можно создать новый. Старый ключ сразу перестанет работать. Это не меняет пароль от аккаунта.

        
        

          
Сохраните файл сейчас: сайт не хранит токен в открытом виде и не сможет показать его повторно.

          

          
          
        

        
Файл server_config.json положите рядом с vvb_dedicated_server.py, затем перезапустите start_server.bat. Сайт не может включать компьютер или запускать игру самостоятельно.

      

      

        
УДАЛЕНИЕ СЕРВЕРА

        
Удаление убирает сервер из списка и отменяет его токен. Запущенный игровой процесс останется работать на компьютере, пока его не остановить вручную.
